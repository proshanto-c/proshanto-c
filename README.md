### 🚀 Highlighted Projects

#### 🔬 [ImageToChaste](https://github.com/proshanto-c/ImageToChaste)
*Automated cell segmentation and geometry extraction pipeline for simulation engines (specifically intended for Chaste).*
* Adapted Meta's **Segment Anything 2 (SAM 2)** to resolve densely packed cell boundaries from microscopy scans, replacing manual tracing.
* Developed computational geometry routines to extract vector contours into structured geometric formats readable by the C++ Chaste engine.
* Includes an interactive zero-setup demo: [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://github.com/proshanto-c/ImageToChaste)
